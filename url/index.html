Réglages

Les liens sont enregistrés dans url/links.json du dépôt, sur la branche publiée par GitHub Pages. Pour en créer ou en supprimer, il faut un jeton GitHub à portée limitée : Settings → Developer settings → Fine-grained tokens → dépôt maxlgz.github.io seul, permission Contents : Read and write. Le jeton reste dans ce navigateur (stockage local) et n’est envoyé qu’à api.github.com. Les liens courts, eux, fonctionnent pour tout le monde. Compter jusqu’à une minute après création pour que GitHub Pages publie le fichier ; en attendant, la redirection lit le dépôt directement.
